Set up a new Laravel project.

The goal is to build a Postman clone application.

Features:
- Users can enter a URL, select an HTTP method, and input parameters (either as JSON or as form data), then preview the API response.
- Users should be able to create projects, each with a name and associated endpoints.
- Include a "Quick Test" tab where users can test an API by entering the URL and seeing the response without creating a project.
